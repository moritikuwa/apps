# いっこまえ

**ゴールから ぎゃくに たどると、きょうの 一歩が 見つかる。**

「できるように なりたいこと」を いちばん上に おいて、
**「じゃあ、いっこまえは？」** を 3回 くりかえして 下へ おりるアプリです。
いちばん下に のこったものが、**今日やること** になります。

親と子が **別々に 道を作って、あとで 見せ合います**。
同じゴールでも 道順が ちがう。そこが 一番おもしろい ところです。

ブラウザだけで動きます。記録はこの端末の中だけに保存され、**どこにも送信されません**。

- 公開ページ　`https://moritikuwa.github.io/apps/ikkomae/`

---

## なぜ作ったか

子どもが つまずくのは「やる気がない」からではなく、
**0 から 100 に いきなり行こうとする** からです。

チアの新しい技をやりたい。でも そこに行くには 道順と 基礎がある。
部屋を片付けたい。でも どこから 手をつけるかで 全部が 決まる。

大人も同じことをします。ゴールだけ見て、あいだを飛ばす。
そして「できなかった」と思って やめる。

このアプリは、その あいだ を **自分の手で 3段 埋める** 練習です。
埋め終わった一番下は、もう「今すぐ できること」になっている。
だから 動ける。

---

## 使い方

### 1. きょうのゴールが出る

お題は アプリが持っています（**31こ**）。まだやっていないものから 日がわりで出ます。
気分が合わなければ「べつの おだいに する」で 次が出ます。

暮らし・できるように・べんきょう・つくる・おかね・ひと の 6種類。
片付け、朝の支度、カレー、逆上がり、二重跳び、九九、貯金、仲直り —— 
どれも **日常に隠れていて、順番を 誰も教えてくれない** ものを選んでいます。

### 2. ふたりで、順番に道を作る

こども → おとな の順で、1台のスマホを 手わたししながら やります。
**前の人の答えは 見えません。** 渡すときに 隠れます。

1人ずつ、こう聞かれます。

```
        ⭐ おふろから 出て ねる じゅんびが できた   ← ゴール
        ↑
        1  ？                                    ← いま えらぶところ
        ↑
        2
        ↑
        3                                        ← ここが きょうやること
```

出てきた **6まいのカードから 1まい タップするだけ**。文字は書きません。
小1でも 手が止まらないようにしてあります。

### 3. 2本の道を 見せ合う

段ごとに 左右にならべて出ます。同じカードを選んでいたら 金色に光ります。

ここで **カードに かくれていた「高さ」が はじめて 見えます**。

| しるし | いみ |
|---|---|
| ●●● | ゴールに近い（もう ほとんど できている） |
| ●● | とちゅう |
| ● | いますぐ できる |

選んでいる あいだは わざと 見せていません。
**カードの文だけを読んで「これは ゴールに 近いか、遠いか」を 自分で はかる**、
それがこのアプリで 一番 きたえたい ところだからです。

道の かたちには 一言つきます。○×はつけません。

| かたち | 出る言葉 |
|---|---|
| ●●● → ●● → ● | 🪜 きれいな はしごに なった |
| ぜんぶ ●●● | 🏔 ぜんぶ ゴールの すぐ手前だね。もう ひとつ 小さく わけられないかな？ |
| ぜんぶ ● | 🐜 すぐ 手が うごくのは つよい。この3つで ゴールまで とどくかな？ |
| とちゅうで 大きくなった | 🔀 じゅんばんを 入れかえたら、どんな みちに なるかな？ |

最後に画面が 一つ聞きます —— **「なんで それを えらんだの？」**
アプリが採点しない代わりに、ここを 親子で 話すのが 本体です。

### 4. きょうやることを 1つだけ 決める

2本の道に出たカードから、1つだけ選びます。**●が少ないものが上に来ます。**

### 5. 次にひらいたとき「やった？」と聞かれる

これが 続ける仕掛けです。

**🔥（つづいた日数）は、道を作った日ではなく、じっさいに やった日だけ のびます。**
考えただけで 火がつくアプリは、考えるのが 上手になるだけで 動けるようにはならないからです。
1日の抜けは ゆるします。

## ひとりでも できます

「ひとりで」を選ぶと 1本だけ作ります。道の かたちの読みと 今日やることは 同じように出ます。

## お題を増やす

お題は [`assets/themes.js`](assets/themes.js) の `IK.THEMES` にまとまっています。
1件は **ゴール1つ ＋ カード12まい（高さごとに 4まいずつ）** です。

```js
{
  id: 'heya',                 // 他とかぶらない短い名前
  emoji: '🧹',
  tag: 'くらし',               // くらし / できるように / べんきょう / つくる / おかね / ひと
  goal: 'へやが ぜんぶ かたづいた',
  cards: [
    { t: 'ゆかに 何も おちていない', s: 3 },   // s:3 ゴールの すぐ手前  ×4
    { t: 'おもちゃを はこに もどした', s: 2 }, // s:2 とちゅう          ×4
    { t: 'タイマーを 5分 かけた', s: 1 }       // s:1 いますぐ できる    ×4
  ]
}
```

守ること。

1. **高さは 4・4・4 で そろえる。** 1回に配る6まいには 必ず 3つの高さを混ぜます。
   かたよらせると「これは 大きすぎないか」を はかる練習に ならなくなります。
2. **ゴールは「〜できた」と 終わった形で書く。** 状態で書くと、逆にたどれます。
3. **カードも「〜した / 〜なった」で書く。** 手順ではなく **できあがった状態** です。
   状態で書くから「その前は？」がつながります。
4. **文字は 小学校低学年が 一人で読める量に。** ひらがな中心、漢字は1〜2年で習うものまで。

`s:1` は「今すぐ 手がうごくこと」です。ここが 弱いと、道の一番下が 現実にならず、
「やった？」に「まだ」が続きます。**s:1 を書くのが 一番むずかしく、一番大事**です。

カードの `id` は 読みこむときに 自動でふられます。書く必要はありません。

## 決めていないこと（わざと）

- **採点しません。** 正解の道は 持っていません。
- **AIにも つなぎません。** 通信は一切しません。圏外でも動きます。
- **自分でお題を入れる欄は ありません。** まずは 型を体に入れる段階と考えています。
  自分の目標を 直接あつかいたくなったら、そこで足します。

## ファイル

```
ikkomae/
├── index.html
├── manifest.json          ホーム画面に追加するための設定
├── sw.js                  圏外でも開くための仕組み
└── assets/
    ├── themes.js          お題のデータ（ここを増やしていく）
    ├── store.js           記録の保存（道・やくそく・火／localStorage）
    ├── game.js            カードの配り方と、道のかたちの読み
    ├── app.js             画面
    ├── style.css
    └── icon.svg
```

スマホでURLを開き、ブラウザの「ホーム画面に追加」を選ぶと、
アプリのように全画面で起動し、圏外でも使えます。
