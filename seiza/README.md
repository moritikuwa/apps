# AI星座

**いま自分に何が抜けているかが、魔法陣で見える。**

Claude を使いこなすための技を6つの星座にして、
「今どこにいるか」と「次に何をすれば最短で進むか」を示すアプリです。

ブラウザだけで動きます。記録はこの端末の中だけに保存され、**どこにも送信されません**。
（設定の「🔌 接続」を自分で押したときだけ、GitHub の公開ページを**読みに行きます**。
それでも送るものはありません。詳しくは[下](#-接続任意)）

- 公開ページ　`https://moritikuwa.github.io/apps/seiza/`

---

## なぜ作ったか

情報が足りないのではなく、**判断できない**のが問題だった。

毎日いろんな人がAIについて発信していて、見れば見るほど
「自分のやり方は合っているのか」「遠回りしていないか」が分からなくなる。
上級者向けの話に振り回されて、時間だけが溶けていく。

だからこのアプリは、情報をためる道具ではなく
**自分の現在地を測って、次の一手を1つに絞る道具**として作っています。

---

## 画面の読み方

魔法陣は **扇（6等分）＝星座**、**輪（内から外）＝段** でできています。

```
        中心 ── いまのレベルと称号
    内の輪 ── 初級
    中の輪 ── 中級
    外の輪 ── 上級
        扇 ── 対話・記憶・技・自走・連結・実務
```

札のかたちも段で変わります。**丸＝初級、ひし形＝中級、六角＝上級**。

| 見た目 | 意味 |
|---|---|
| 金色の輪が脈打つ | ⚡ 前提が揃っていて、**今すぐ取りに行ける** |
| 点線の輪 | 🔒 前提が足りない。**まだ早い** |
| 札が光る・線が繋がる | 取得が進んでいる |
| 名前が出ている | いま**一番効く3つ** |

暗い札がそのまま「自分の穴」です。
指で引っぱると動き、二本指でつまむと拡大できます。

## 使い方

### 1. まず現在地を埋める（📊 ステータス）

40個の技が一覧で並んでいます。いまの自分に当てはまるものを押していくだけ。
正直に押すほど「次の一手」が当たります。

| 印 | 意味 |
|---|---|
| ☆ | 知らない |
| ✦ | 知ってる |
| ✧ | やったことがある |
| ★ | 一人でできる |
| 🌟 | **人に教えられる** |

### 2. 一つ取りに行く（⚡ 次の一手）

一番うすい星座から、いま効く星を出します。札を押すと4段階で出ます。

**❶ なぜ今これなのか**
**❷ 考え方の芯** — ここが分かれば応用が効く
**❸ やってみる** — 実行 → 確認 → 改善（下記）
**❹ 自分の言葉で言えたら光る** — 説明できて初めて習得

### 3. 実行 → 確認 → 改善 をとことん回す

読んで終わりにしないための仕掛けです。1回やるごとに3つ書き残します。

| | 書くこと |
|---|---|
| **実行** | 何をやったか |
| **確認** | どうなったか（うまくいった所・いかなかった所） |
| **改善** | 次はこう変える |

記録すると自動で ✧（やったことがある）まで進み、
札には「◯回まわした」が出ます。**回した数がそのまま身についた量**です。

書いた「改善」は 📊ステータス の **♻️ 改善メモ** に集まります。
まとめてコピーして CLAUDE.md や技に書き足せば、同じ失敗がそこで消えます。
（これは技「判断基準を書き残す」「差し戻しで賢くする」そのものです）

### 4. 話して採点してもらう

「🌟 話して採点してもらう」を押すと採点用の文がコピーされます。
Claude に貼って、続きに自分の言葉で説明を書いてください。
**実行記録も一緒に貼られる**ので、机上の理解で止まっていないかまで見てもらえます。
甘く採点させないための指示も入っています。

### 5. 続けるための仕掛け

**報酬の重心は「チェック」ではなく「実行」に置いています。**
押すだけで気持ちよくなるアプリは、実力が伴わないままレベルだけ上がって、
結局それが一番の遠回りになるからです。

| | 何が起きるか | 伸ばし方 |
|---|---|---|
| 🎯 **今日の一手** | 毎日ひとつだけ提示される。その日のうちは変わらない | 効く順の上位8つから、日替わりで |
| 🔥 **火（連続日数）** | 上のバーに出る。今日まだなら灰色 | **実行を記録した日だけ**伸びる。1日の抜けは許す |
| 🏅 **印** | 13個。ステータス画面で集まっていく | 実行の回数・改善の件数・連続日数・取り切った数 |
| ⚡ **解放** | 星を★にすると先の星が開く。その場で数えて出る | 前提を満たす |
| 👑 **称号** | 6段階。変わると全画面で祝う | 習得率 |

**星を押しただけでは、🔥も印も一切動きません。**
実際に手を動かして「実行→確認→改善」を記録したときにだけ動きます。

印は4つが伏せられていて（？？？）、進むと出てきます。

### 🆕 星が増えたとき

技を足すと、既に使っている人の画面には **🆕 として出ます**。
魔法陣では緑の点が付き、「次の一手」の頭に増えた星が並びます。開けば消えます。

星が増えると習得率の分母も増えるので、**数字は一時的に下がります**。
腕が落ちたわけではなく、空が広がっただけです。

そこで **一度届いた高さは消しません**。上のバーには `40%` の下に小さく `最高50%` が出て、
📊ステータスにも「これまでの最高は 50%（日付）」が出ます。
（技のデータに `added: '日付'` を書くと🆕になります。自動収集をつないだときも同じ見え方になります）

### 6. 段は自動で切り替わる

習得率に応じて、初級・中級・上級が自動で切り替わります。

- **初級**（〜15%）… 用語の説明が最初から開く
- **中級**（15〜45%）… 用語は畳まれ、必要なときだけ開く
- **上級**（45%〜）… 用語は畳み、代わりに「もう一段上なら」が開く

## 技を増やす

技のデータは [`assets/skills.js`](assets/skills.js) の `SZ.SKILLS` にまとまっています。
新しい技を見つけたら、同じ形式で1件足すだけ。
**位置は書きません。星座と段から自動で魔法陣に並びます。**

```js
{
  id: 'x1',                 // 他とかぶらない短い名前
  name: '星の名前',          // 札を押したときに出る
  icon: '🌙',               // 札の絵（絵文字ひとつ）
  const: 'jisou',           // どの星座か（扇）
  tier: 2,                  // 1=初級 2=中級 3=上級（輪）
  req: ['j3'],              // 前提の技。★未満なら「まだ早い」になる
  added: '2026-08-11',      // 後から足したときだけ書く。🆕として出る
  why:  'なぜ今これなのか',
  core: '考え方の芯',
  do:   '小さく1回やること',
  say:  '自分の言葉で言えたら光る、その問い',
  next: 'もう一段上ならこう出来る',
  terms:[{ w:'用語', d:'説明' }]
}
```

`req` を書くと、その技は前提が★になるまで「🔒 まだ早い」になります。
**ここがこのアプリの肝**で、上級の情報に手を出して遠回りするのを止めるための仕掛けです。
新しい技を足すときは、必ず `req` を考えてから足してください。

札がぶつからない間隔は、札の大きさ・半径・隣の輪との距離から自動で計算されます
（`calc.js` の `SZ.layout`）。角度で足りないぶんは内外に互い違いにずらして稼ぎ、
そのずらし幅も隣の輪にめり込まない範囲に収まります。
**技が増えても、手で位置を直す必要はありません。**

## 🔌 接続（任意）

**使わなくてかまいません。** 押さなければ、このアプリは今までどおり何も外に出しません。

⚙️設定 の「🔌 接続」を押すと、GitHub の**公開ページを読みに行くだけ**の状態になります。

| | |
|---|---|
| 外に出すもの | **なし**（読むだけ）。画面にもそう出ます |
| 要るもの | ログインもパスワードも鍵も**不要** |
| 読みに行く先 | `moritikuwa/apps` の公開ページ（`api.github.com`） |
| 送るもの | GET が2本だけ。本文なし。Cookie も送りません（`credentials:'omit'`） |
| 見えるようになるもの | 技の一覧が更新されたか／集まった候補 |
| やめ方 | 「接続を切る」を押すと `seiza.link.v1` ごと消えて元に戻る。**星の記録は消えません** |

候補は**まだ星ではありません**。「気になる」を押したものだけを、次の段階で技として足します。
外から来た文章は必ず文字として出します（HTMLとしては解釈しません）。

接続でできること・できないことは [`docs/connection-feasibility.md`](../docs/connection-feasibility.md) にまとめています。
**Claude のアカウントに直接つなぐ方法は存在しません**（公式APIが無く、ブラウザからはCORSで塞がれています）。

## これから足していくもの

- **自動収集** — GitHub Actions が毎朝 YouTube・X などを見に行き、新しい技を候補として集める
- **持ち技との照合** — 集めた候補を、いまのレベルと突き合わせて
  「⚡今すぐ効く／🔒まだ早い／⚠先にこれが要る」に仕分けてから出す
- **選んでスキル化** — 取ると決めた技を、そのまま Claude のスキルにする

収集も追加も **Pull Request の形**で出します。
森さんが中身を見てマージするまで、`assets/skills.js` は1文字も変わりません。
サーバーは立てません。

## ファイル

```
seiza/
├── index.html
├── manifest.json          ホーム画面に追加するための設定
├── sw.js                  圏外でも開くための仕組み
└── assets/
    ├── skills.js          技のデータ（ここを増やしていく）
    ├── badges.js          印のデータ（条件はすべて実行量に紐づく）
    ├── store.js           記録の保存（状態・実行記録・火・印・最高到達率／localStorage）
    ├── calc.js            魔法陣の配置・レベル・次の一手・今日の一手・印の判定
    ├── map.js             魔法陣の描画と操作
    ├── link.js            接続（任意・読み取り専用）。繋がなければ何もしない
    ├── app.js             画面
    ├── style.css
    └── icon.svg
```

スマホでURLを開き、ブラウザの「ホーム画面に追加」を選ぶと、
アプリのように全画面で起動し、圏外でも使えます。
