# AI星座

**いま自分に何が抜けているかが、星で見える。**

Claude を使いこなすための技を6つの星座にして、
「今どこにいるか」と「次に何をすれば最短で進むか」を示すアプリです。

ブラウザだけで動きます。記録はこの端末の中だけに保存され、どこにも送信されません。

- 公開ページ　`https://moritikuwa.github.io/apps/seiza/`

---

## なぜ作ったか

情報が足りないのではなく、**判断できない**のが問題だった。

毎日いろんな人がAIについて発信していて、見れば見るほど
「自分のやり方は合っているのか」「遠回りしていないか」が分からなくなる。
上級者向けの話に振り回されて、時間だけが溶けていく。

だからこのアプリは、情報をためる道具ではなく
**自分の現在地を測って、次の一手を1つに絞る道具**として作っています。

---

## 使い方

### 1. まず現在地を埋める（📊 ステータス）

35個の技が一覧で並んでいます。いまの自分に当てはまるものを押していくだけ。
正直に押すほど「次の一手」が当たります。

| 印 | 意味 |
|---|---|
| ☆ | 知らない |
| ✦ | 知ってる |
| ✧ | やったことがある |
| ★ | 一人でできる |
| 🌟 | **人に教えられる** |

### 2. 星図を見る（🌌）

技が星として並び、前提が線で繋がっています。上から下へ、
**対話 → 記憶 → 技 → 自走 → 連結 → 実務** の順に進みます。

- ⚡ 金色の輪 … 前提が揃っていて、**今すぐ取りに行ける**
- 🔒 点線の輪 … 前提が足りない。**まだ早い**
- 🌟 強く光る … 人に教えられる水準

暗い星がそのまま「自分の穴」です。
指で引っぱると動き、二本指でつまむと拡大できます。

### 3. 一つ取りに行く（⚡ 次の一手）

一番うすい星座から、いま効く星を出します。星をタップすると4段階で出ます。

1. **なぜ今これなのか**
2. **考え方の芯** — ここが分かれば応用が効く
3. **小さく1回やる** — 手を動かす
4. **自分の言葉で言えたら光る** — 説明できて初めて習得

「話して採点してもらう」を押すと採点用の文がコピーされるので、
Claude に貼って、続きに自分の言葉で説明を書きます。
甘く採点させないための指示も入っています。

### 4. 段は自動で切り替わる

習得率に応じて、初級・中級・上級が自動で切り替わります。

- **初級**（〜15%）… 用語の説明が最初から開く
- **中級**（15〜45%）… 用語は畳まれ、必要なときだけ開く
- **上級**（45%〜）… 用語は畳み、代わりに「もう一段上なら」が開く

## 技を増やす

技のデータは [`assets/skills.js`](assets/skills.js) の `SZ.SKILLS` にまとまっています。
新しい技を見つけたら、同じ形式で1件足すだけで星図に星が増えます。

```js
{
  id: 'x1',                 // 他とかぶらない短い名前
  name: '星の名前',          // 画面に出る
  const: 'jisou',           // どの星座か
  tier: 2,                  // 1=初級 2=中級 3=上級
  x: 250, y: 1500,          // 星図の中の位置
  req: ['j3'],              // 前提の技。★未満なら「まだ早い」になる
  why:  'なぜ今これなのか',
  core: '考え方の芯',
  do:   '小さく1回やること',
  say:  '自分の言葉で言えたら光る、その問い',
  next: 'もう一段上ならこう出来る',
  terms:[{ w:'用語', d:'説明' }]
}
```

`req` を書くと、その技は前提が★になるまで「🔒 まだ早い」になります。
**ここがこのアプリの肝**で、上級の情報に手を出して遠回りするのを止めるための仕掛けです。
新しい技を足すときは、必ず `req` を考えてから足してください。

座標は 520 × 2740 の範囲。星座ごとの縦の帯はだいたい次のとおりです。

| 星座 | y の範囲 |
|---|---|
| たいわ座 | 120〜400 |
| きおく座 | 590〜840 |
| わざ座 | 1030〜1310 |
| じそう座 | 1440〜1690 |
| れんけつ座 | 1910〜2160 |
| じつむ座 | 2330〜2600 |

## これから足していくもの

- **自動収集** — YouTube・X などを毎朝見に行き、新しい技を候補として集める
- **持ち技との照合** — 集めた候補を、いまのレベルと突き合わせて
  「⚡今すぐ効く／🔒まだ早い／⚠先にこれが要る」に仕分けてから出す
- **選んでスキル化** — 取ると決めた技を、そのまま Claude のスキルにする

どちらもブラウザだけでは動かないので、Claude Code 側から
`assets/skills.js` を書き足す形で足していきます。

## ファイル

```
seiza/
├── index.html
├── manifest.json          ホーム画面に追加するための設定
├── sw.js                  圏外でも開くための仕組み
└── assets/
    ├── skills.js          技のデータ（ここを増やしていく）
    ├── store.js           記録の保存（localStorage）
    ├── calc.js            レベル・パラメーター・次の一手の計算
    ├── map.js             星図の描画と操作
    ├── app.js             画面
    ├── style.css
    └── icon.svg
```

スマホでURLを開き、ブラウザの「ホーム画面に追加」を選ぶと、
アプリのように全画面で起動し、圏外でも使えます。
