# apps — 自作アプリ置き場

ブラウザだけで動く小さな道具を、アプリごとにフォルダで置いています。
サーバーもインストールも不要で、`index.html` を開けば動きます。

入力したデータは**その端末のブラウザの中だけ**に保存され、どこにも送信されません。
このリポジトリで公開しているのはプログラムだけで、記録した中身は公開されません。

## 置いてあるもの

| フォルダ | アプリ | 何をするもの |
|---|---|---|
| [`yoilog/`](yoilog/) | **酔いログ** | 毎日の晩酌と、翌朝のからだ・眠りを記録して突き合わせる。飲んだ量が体に何をしているかを数字で見る |

## 公開ページ

GitHub Pages を有効にすると、それぞれ次のURLで開けます。

- 一覧　　　`https://moritikuwa.github.io/apps/`
- 酔いログ　`https://moritikuwa.github.io/apps/yoilog/`

スマホでURLを開き、ブラウザの「ホーム画面に追加」を選ぶと、
アプリのように全画面で起動し、圏外でも使えます。

## 新しいアプリを足すとき

1. 直下に新しいフォルダを作る
2. `index.html` を置く
3. このREADMEの表と、`index.html`（一覧ページ）にリンクを1行足す
