# 酔いログ / YOI-LOG

**今日の一杯が、明日のからだに何をするか。**

毎日の晩酌を記録し、翌朝のからだと眠りを突き合わせて、
「お酒が自分に何をしているか」を数字で見るためのカレンダー型アプリです。

インストール不要。`index.html` をブラウザで開くだけで動きます。
記録はすべて端末の中（localStorage）に保存され、どこにも送信されません。

---

## このアプリの芯

よくある飲酒記録アプリと違うのは、**本人の言い分をデータで検証する** ところです。

> 「酒を飲んで酔っ払わないと寝れない」

飲む人がよく言うこの一言を、責めるのではなく、**本人の記録で確かめます**。

- 飲んだ夜と、飲まなかった夜の **睡眠スコアを並べて比較**
- 「寝るために飲んだ夜」だけを取り出して、**寝つき／中途覚醒／朝のスッキリ感**を突き合わせ
- 飲んだ量と翌朝の眠りの質の **散布図と回帰直線**

たいていの場合、こう出ます ――
**寝つきだけは速くなる。しかし夜中に起きる回数が増え、朝のスッキリ感は落ちる。**
眠りを買ったのではなく、前半に借りて後半に返しているだけ、ということが自分の数字でわかります。

そしてもうひとつ。数字は「怖く」出します。
「ビール2本」ではなく「**純アルコール40g／肝臓の残業7時間／抜けきるのは翌朝3時24分**」と表示します。
やめさせるためではなく、**本数が1本減れば十分**、という設計です。

## 画面

| 画面 | 中身 |
|---|---|
| 🏠 **きょう** | 今日の純アルコール量、肝臓が働く時間、抜けきる時刻。主人公アバター（腹まわりは飲酒量とカロリーで変化）。連続飲酒日数と最後の休肝日。気をつけたいサイン |
| 📅 **カレンダー** | 月表示。1日ずつ色（適量／やや多い／リスク／負担大／危険域）と、翌朝のダメージ顔で塗られる。日付をタップして記録 |
| 🫀 **からだ** | 今夜からだの中で何が起きるかの時間割。臓器が光るアバター。30日／1年で体を通った量の換算 |
| 📊 **ふりかえり** | 飲んだ翌朝 vs 飲まない翌朝の比較、寝酒の検証、相関の散布図、30日グラフ、月別トレンド、飲んだ理由の内訳 |
| ⚙️ **設定** | 体重・性別などのプロフィール、書き出し／読み込み、急性アルコール中毒のサイン、相談先 |

## 記録できること

### 🍶 その夜のお酒

- **種類**：ビール、発泡酒、日本酒、焼酎（乙類・甲類）、泡盛、ウイスキー、ブランデー、ジン、ウォッカ、ラム、テキーラ、ワイン（赤・白）、缶チューハイ、ストロング系、レモンサワー、梅酒、マッコリ、紹興酒、ノンアル、その他
- **割り方**：ストレート、ロック、水割り、ソーダ割り、お湯割り、緑茶割り、ウーロン割り、**牛乳割り、豆乳割り**、コーラ、ジンジャーエール、トニック、ジュース、カルピス、ヨーグルト、ほうじ茶・麦茶
  - 濃さ（原液 : 割り材）も 1:1 〜 1:6 で選べます
  - 割り方ごとに「吸収の速さ」と「割り材のカロリー」が違うことを、その場で説明します
- **カクテル**：ハイボール、ジントニック、モスコミュール、スクリュードライバー、カシスオレンジ、カルーアミルク、キューバリブレ、マティーニ、マルガリータ、モヒート、ロングアイランドアイスティー、サワー、シャンディガフ
- 杯数、お酒代、**なぜ飲んだか**（習慣／寝るため／ストレス／ご褒美／付き合い／嬉しいこと／手持ち無沙汰／食事に合わせて）

### 🌅 その朝のからだ

- **眠り**：寝た時刻、起きた時刻、寝つくまでの時間、夜中に目が覚めた回数、夜中のトイレ、起きたときのスッキリ感（5段階）
- **考え事・不安**（4段階）と、その中身のメモ
- **「前の晩は寝るために飲んだ」** チェック ← 検証の要
- **ダメージ**（各4段階）：頭痛／吐き気・胃もたれ／だるさ／口の渇き／動悸／下痢／記憶があいまい／やる気が出ない／イライラ・不安／むくみ

> その日の朝の記録は、**前日の夜のお酒の結果**として自動的に紐づけられます。

## 計算のしかた

| 項目 | 式・根拠 |
|---|---|
| 純アルコール量 | 量(ml) × 度数(%) ÷ 100 × 0.8 |
| 分解にかかる時間 | 純アルコール(g) ÷（体重(kg) × 0.1）＋ 吸収の0.5時間 |
| 血中アルコール濃度 | Widmark式：A(g) ÷（体重kg × r）　r＝男性0.68／女性0.55、下降 0.15‰/時 |
| カロリー | 純アルコール(g) × 7.1 ＋ お酒の糖質分 ＋ 割り材 |
| 利尿による水分損失 | 純アルコール1gあたり 約10ml |
| 睡眠スコア（0〜100） | 睡眠時間（7時間を最良）／寝つき／中途覚醒／夜間のトイレ／起床時のスッキリ感の合成 |
| ダメージ（0〜100） | 10項目 × 0〜3 の合計を100点換算 |

**基準値**（厚生労働省「健康に配慮した飲酒に関するガイドライン」2024年2月 ほか）

- 20g／日 … 節度ある適度な飲酒の目安（1日平均）
- 40g／日（男性）・20g／日（女性） … 生活習慣病のリスクを高める量
- 60g／日 … 毎日続けると数週間で脂肪肝が進みやすいとされる目安

いずれも**目安**です。分解速度や体への影響には、体質（とくに ALDH2 の働き）・体調・服薬・持病によって大きな個人差があります。

## 使い方

### そのまま開く

`index.html` をダブルクリックするだけで動きます（オフライン可・サーバー不要）。

### スマホのホーム画面に置く

`https://moritikuwa.github.io/apps/yoilog/` をスマホのブラウザで開き、
「ホーム画面に追加」を選ぶと、アプリのように全画面で起動し、圏外でも使えます
（`manifest.json` と `sw.js` を同梱）。

### ローカルサーバーで確認する

```sh
npx http-server . -p 8080     # または  python3 -m http.server 8080
```

### 動きを先に見たい

設定 → **「お試しデータを入れる」** で、45日ぶんのサンプル記録が入ります。
主人公は40代前半、ちょっとお腹が出ていて、ほぼ毎日飲む人です。
グラフや判定がどう出るか、実データを入れる前に確認できます（あとから消せます）。

---

## データについて

- 保存先は **その端末のブラウザの localStorage だけ**。サーバーへの送信は一切ありません
- ブラウザのデータを消すと記録も消えます。設定画面から **JSON で書き出して**保管してください
- 書き出した JSON は、同じ画面から読み込めます（機種変更・バックアップ用）

## ファイル構成

```
index.html          画面の骨組み
manifest.json       ホーム画面に追加するための情報
sw.js               オフライン用サービスワーカー
assets/
  style.css         見た目
  data.js           お酒・割り方・カクテル・記録項目・基準値・相談先のマスタ
  calc.js           純アルコール量、カロリー、分解時間、血中濃度、睡眠スコア、回帰
  store.js          localStorage への保存・読み込み・書き出し
  stats.js          飲んだ夜 vs 飲まない夜の比較、相関、期間集計、注意サイン
  body.js           主人公アバター（SVG）と、体内で起きることの時間割
  charts.js         棒グラフ・散布図・比較バー・折れ線（すべて自前のSVG）
  app.js            画面の描画と操作
  icon.svg          アイコン
```

外部ライブラリ・ビルド・通信はありません。素の HTML/CSS/JavaScript だけです。

## ⚠️ 大切なこと

**このアプリは医療機器ではありません。** 表示される数値はすべて一般的な計算式による目安であり、
医学的な診断や治療の代わりにはなりません。

### 急性アルコール中毒のサイン — ひとつでも当てはまったら 119番

- 揺すっても、大声で呼んでも起きない
- いびきをかいて眠り込み、呼吸が浅い・不規則
- 呼吸が10秒に1回以下、または止まる
- 体が冷たい、顔が青白い・紫っぽい
- 吐いたものが口に残ったまま眠っている

**「寝かせておけば醒める」は間違いです。**
ひとりにせず、吐いたもので窒息しないよう必ず横向きに寝かせ、保温してください。

### 相談できるところ

- お住まいの都道府県・政令市の **精神保健福祉センター**（無料・匿名でも相談できます）
- **保健所**（本人だけでなく、家族からの相談も受け付けています）
- **全日本断酒連盟 / AA（アルコホーリクス・アノニマス）**（見学だけでも参加できます）
- **かかりつけ医・内科**（まず血液検査 γ-GTP、AST/ALT から）

アルコールの問題は、意志の強さの問題ではなく、体と脳に起きる変化です。
「量を減らしたいのに減らせない」と感じたら、早いほど戻りやすいことがわかっています。
